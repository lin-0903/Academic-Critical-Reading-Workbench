# Academic Critical Reading Workbench — Weeks 1–4

A bilingual, browser-based critical reading workbench for **Conservation Principles, Practices & Ethics**.

## What is included
- Week 1–4 reading guides with argument maps, close-reading anchors, terminology, multiple-choice checks, and open-ended prompts.
- Clickable weekly and cross-week concept maps.
- Personal annotations, study notes, and Obsidian-compatible Markdown export.
- JSON export/import for backups.

The entire interactive application and its study-guide data are embedded in **`index.html`**. No build step or server is required.

## GitHub Pages setup
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. The public URL should be: https://lin-0903.github.io/Academic-Critical-Reading-Workbench/

## Privacy, sources, and backups
This public repository deliberately does **not** distribute copyrighted course PDFs. Use the source links in the interface or open your own PDF locally.

Progress, quiz answers, notes, and highlights are saved only in that browser's `localStorage` for the site's origin. They do not sync automatically with GitHub or Obsidian; export JSON backups periodically. Switching from a local file to GitHub Pages does not automatically carry local browser data across origins.

Study summaries are reading aids, not original quotations. Check cited pages and paragraphs against your assigned readings before using them in academic work.
